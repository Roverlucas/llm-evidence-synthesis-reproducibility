## Notes on Author Order

The order in this table reflects current manuscript convention (lead → contributing → senior/advisor). OSF "Contributor" lists support reordering at any time via drag-and-drop. The "Bibliographic Contributor" flag controls whether the person appears in the auto-generated citation; the senior author (Tadano) is placed last following Brazilian academic convention (advisor as last author).
